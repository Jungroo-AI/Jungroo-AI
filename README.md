# Jungroo AI Labs

Jungroo AI Labs builds private AI systems for enterprises in regulated industries: domain-specific language models,
agentic workflows and full-stack applications, deployed on-premise or in the customer's own cloud, so their data
never leaves their environment.

We also publish open models built on the same principle: small enough to run inside your own infrastructure.

## Open models

**[ReDefiNER](https://github.com/Jungroo-AI/redefiner)**: a 0.8B model that extracts the entities you define in a
plain-English rulebook. It runs on a CPU and is free under Apache 2.0.
[Model](https://huggingface.co/jungroo-ai/redefiner-0.8b) ·
[Benchmarks](https://github.com/Jungroo-AI/redefiner/tree/main/benchmarks)

Need it on your own data? We write and test rulebooks with you and run ReDefiNER on your own servers:
[jungroo.com/redefiner](https://jungroo.com/redefiner/) or hello@jungroo.com.
